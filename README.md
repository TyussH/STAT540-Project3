# STAT540 - Project 3: Option 1

## Overview
This project uses R to analyze health data, focusing on building and comparing statistical models like logistic regression, KNN, and Naive Bayes. The goal is to make accurate predictions and evaluate model performance.

## Motivation
The project was a learning opportunity to practice data analysis, model training, and evaluation using real-world datasets in R. It helped strengthen my understanding of classification and exploratory data analysis.
